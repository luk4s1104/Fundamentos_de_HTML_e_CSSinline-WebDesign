# 🌐 Fundamentos de HTML e CSS Inline

Este repositório foi criado para documentar e praticar os conceitos estruturais básicos do **HTML5**, além de aplicar estilizações iniciais diretamente nas tags utilizando o atributo **CSS Inline**.

## 🎯 Objetivos do Código

*   **Estruturação Semântica:** Uso correto de tags como `<header>`, `<nav>`, `<section>`, `<article>`, `<aside>` e `<footer>`.
*   **Hierarquia de Títulos:** Aplicação e alinhamento de cabeçalhos do `<h1>` ao `<h6>`.
*   **Formatação de Texto:** Utilização de tags nativas para estilizar e enfatizar blocos de texto.
*   **Estilização Inline:** Aplicação direta de propriedades CSS para modificar cores, alinhamentos e tamanhos de fonte sem um arquivo externo.

---

## 🛠️ Recursos Praticados no Código

### 1. Elementos Estruturais (Semântica)
*   `<header>` / `<footer>`: Definição de cabeçalho e rodapé da página.
*   `<nav>`: Menu de navegação por links internos (`#posts`, `#lateral`, `#rodape`).
*   `<section>` / `<article>`: Segmentação do conteúdo principal e criação de posts independentes.
*   `<aside>`: Barra lateral destinada a conteúdos relacionados.

### 2. Formatação e Hierarquia de Texto
*   `<strong>` e `<em>`: Aplicação de **negrito** e *itálico*.
*   `<sub>` e `<sup>`: Textos <sub>subscrito</sub> e <sup>sobrescrito</sup>.
*   `align="center/left/right"`: Atributo HTML nativo utilizado para alinhar cabeçalhos.

### 3. CSS Inline Praticado (`style=""`)
*   `text-decoration: line-through;` — Criação de texto riscado.
*   `text-decoration: underline;` — Inclusão de linha abaixo do texto.
*   `color: blue;` — Alteração da cor do texto para azul.
*   `font-size: large;` — Aumento do tamanho do texto.
*   `text-align: center / justify;` — Alinhamento centralizado de blocos (`<div>`) e texto justificado (`<p>`).
